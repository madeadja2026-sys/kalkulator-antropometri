# CKG Puskesmas Ngalupolo — V11 PWA

PWA app shell for GitHub Pages. This folder is published at the /ckg-v11/ path.

- index.html: CKG V11 app
- manifest.webmanifest: install metadata
- sw.js: offline app-shell cache
- icons/icon.svg: application icon

Patient records remain in browser localStorage on the device. They are not uploaded to GitHub. Open the app online once before relying on offline mode. Export JSON backups regularly. Do not put patient data into this repository.
